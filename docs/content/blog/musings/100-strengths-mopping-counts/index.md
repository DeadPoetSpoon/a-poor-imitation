# 前言

一周的休假期间我整理了与笔友的信件之后去体验了诸多我曾经没有体验的项目：四重奏、脱口秀、异宠体验馆、互动剧...最终发现这些实在不是我的兴趣，并且自己一直做着自己喜欢的事情：书籍、电影、游戏，休假期间整理信件、看电影、通关《毁灭战士：黑暗时代》是我最开心的时刻，或许人们总是能够找到自己舒适的生活，这次的休假像是某种：“体验之后没遗憾了吧，之后的生活要关注自己热爱之事哦！”的告诫。无论如何开始吧，开始未尽的这些事情吧！
