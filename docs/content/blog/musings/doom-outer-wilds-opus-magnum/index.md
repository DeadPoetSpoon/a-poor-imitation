# 毁灭战士·星际拓荒·巨著

将这三者并列是想讨论游戏中:身体和脑子参与程度的比例。抽象引申一点是感受和输出的比例，“身体”感受代表着将你自已全然交给游戏,沉进它的节奏,“脑子”输出代表着去理解游戏的逻辑,参与游戏,验证自己的想法,这样的区别也代表着游戏的“愉悦”感来自哪里:是完成了一场站斗还是解决了一个迷题,是体验了一段故事还是攻克了最终B0SS

# 毁灭战士

毁灭战士当是“战斗爽”的标干,初玩毁灭战士时,极致的处决动画给我留下了深刻的印记,最终形态的老式霰弹枪撕碎眼前的恶魔,哐哐几下,处决越看越呆的精英,后来毁灭战士黑暗纪元弹反的加入让战斗爽更是上了一个等级，再加上拳拳到肉的机甲拳击,引用一位网友的评论“直接抚平你的大脑褶皱“你别问我剧情,我只知道音乐响起,我要撕碎眼前一切让我不爽的东西!但这却很符合毁灭战士的人设,而这种畅快的游玩体验最直接地表达了游戏最本初的目的:“愉悦”。

# 星际拓荒

星际拓荒我很喜欢,我认为它一定程度平衡了身体和脑子的参与,漫漫太空实时演算的各异星球每一个星球都是全新的体验,而当你在星际穿梭渐渐将各处细微的回忆拼凑,曾经那些鲜活的生命和如今正在鲜活的生命在完成某种宏大的事情:无止境的探索,再一次出发的勇气,既使对着攻略跳过所有迷团（这几乎不会发生）,你也将获得一段美丽的故事。它的解迷部份也足够优秀,那些“尤里卡时刻”至今我都想要重新再体会一次,你在一个星球无意得知的信息很可能是另一个星球的关键线索,这种断裂的非连贯知识会层层堆叠直到某个时刻突然爆发,那种愉悦是属于脑子的，世界大爆炸又如何?我到过。

# 巨著

巨著是我玩过十分纯粹的迷题游戏,足够简单清晰的机制,鼠标点点点就能完成,你的身子几乎没有反馈,没有什么故事情节只有一道道愈来俞复杂的迷题等着你去破解,这样的体会让我联想到小时在诺基亚手机游玩数独的乐趣,巨著有一项让我很满意的地方,它的解是多样的,你可以追求效率,可以追求成本，可以追求美观，甚至你可以用机械臂填满屏慕,仅仅是因为你想这么做，即使这样你也可以通关,这种“宽松”给了脑子巨大的发挥机会,给“愉悦“感腾出了空间。

# 结语

我选不出我最喜爱的两者比例,不过在我工作一天后我最喜欢毁灭战士的畅快,在我放小长假时我享受星际拓荒浪漫的探索,在我放长假时我更愿意动动脑子摆弄巨著里的机械臂。游戏总能在各种时刻给我快乐陪伴,这便也是游戏的一大魅力吧!
