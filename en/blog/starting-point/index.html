The origin, purpose, and principles of this project

🤖 AI Translation Notice: This post has been translated from Chinese to English by an AI.

Origin

My Own Game

I've always wanted to make my own game. Perhaps a better description would be: a tool for recording experiences — whether my own, my family's, or stories I've heard. Actually, rather than limiting it to "realistic" "experiences," defining it as "unbounded imagination" — stories — is broader and more feasible!

Based on my current thinking: the core of any story must be people and the interactions between them. So the core of this storytelling game is all the people participating in the story (including the player) and their interactions with each other.

That's when the name A Poor Imitation popped into my mind. Its English abbreviation happens to be API — isn't this somewhat strange game just a crude imitation of our massive online game "Earth Online"? And the actions we take in this "game" are just like "calling APIs" — so what I'm writing now can be called API Docs.

Learning

I've always wanted to learn new things, and this is a perfect opportunity.

Ultimately I've chosen GitHub, Rust, Bevy, Aseprite, and Sonic-Pi as my tools. I hope this game-making journey will help me become proficient with them.

I also hope it will help improve my English skills. It would be even better if I could learn a new language along the way.

And of course, most importantly, learning about people, life, meaning, the world...

Film

I've always loved film, and I always will.

This is also one of the main reasons A Poor Imitation revolves around stories.

Elements that film cares about — screenwriting, performance, cinematography, mise-en-scène, editing, audiovisual language, etc. — must also be paid attention to in game production.

And of course, this means video production is essential.

When we have stories and the experience of participating in them, how to present the story becomes an important task.

Purpose

With the groundwork laid by the origin, the purpose is already clear:

  • Complete the production of A Poor Imitation
  • Learn GitHub
  • Learn Rust
  • Learn Bevy
  • Learn Aseprite
  • Learn Sonic-Pi
  • Improve English proficiency
  • Improve design skills
  • Improve film-related abilities
  • Learn video production
  • So many things to learn!
  • Other meaningful things

Principles

  • GitHub, Rust, Bevy, Aseprite, Sonic-Pi first
  • Use spare time
  • Pursue the latest
  • Be open and inclusive
  • Use the GNU AGPL-3.0 license
  • Record at any time
  • If it runs, it's a success

Mode of Operation

The entire project will be treated as a hobby without setting detailed goals. Everything will start from casual musings.
